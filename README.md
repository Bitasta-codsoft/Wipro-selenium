# Wipro Selenium

This repository contains my Wipro training assignments, Selenium automation capstone project, and certificates.

## Repository Contents

### 1. Assignments

This folder contains the assignments completed during the Wipro training program.

[View Assignments](./Assignments/)

### 2. Selenium Capstone Project

This folder contains my Selenium WebDriver automation project developed using Python and pytest.

The project automates an e-commerce purchase workflow using the TutorialsNinja OpenCart Demo website.

Key features include:

- Browser automation using Selenium WebDriver
- User login
- Product search
- Add product to cart
- Update product quantity
- Cart verification
- Screenshot capture
- Alert handling
- JSON test data
- Page Object Model (POM)
- HTML test report generation

[View Selenium Capstone Project](./Project/)

### 3. Certificates

This folder contains certificates obtained during the training and learning process.

[View Certificates](./Certificates/)
